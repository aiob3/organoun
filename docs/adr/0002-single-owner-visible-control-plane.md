# Concentrar o Organoun em uma Sessão Proprietária visível

Este ADR registra a razão das decisões hoje normatizadas pela [Constituição Organoun/RFC-0001, P-003 a P-010](../../.spec/constituicao.md): concentrar autoridade, observabilidade e limpeza numa Sessão Proprietária evita propagação e split-brain. A hipótese distribuída nunca foi aprovada; este ADR não reproduz a política e não possui autoridade operacional.
